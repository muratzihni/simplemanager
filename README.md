# The Simple Game (simplemanager)

Kişisel, ticari olmayan bir futbol menajerlik oyunu projesi.

## Klasörler
- `design/` — claude.ai tasarım tuvalinden alınan 10 ekran (`*.dc.html`) ve `canvas.json`.
  Ekranlar: Intro, Main (ana menü), UlkeSecimi, LigPiramidi (menajer profili), KayitliOyunlar,
  Ayarlar, VeriEditoru, OnurListesi, Yapimcilar, MacMotoru (maç motoru prototipi).

## Notlar
- Ayarlar `localStorage` içinde `td-ayarlar-v1` anahtarıyla tutulur.
- Ayarlar'daki Arayüz ölçeği, Yüksek kontrast, Hareketi azalt ve Maç hızı tüm ekranlarda uygulanır.
- Eğlence modu kuralları ileride maç motoruna bağlanmak üzere önceden hazırlanmıştır.
