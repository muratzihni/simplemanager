# Çeviriler

`kaynak_N.json`: Türkçe arayüz metinleri (dizi). `ceviri_N/XX.json`: aynı sıradaki çeviriler (XX = dil kodu).
Yer tutucular: `{n}` sayı, `{c}` ülke adı, `{x}` serbest ad.
18 dil: EN DE FR ES PT IT NL SV RU UK PL RO AZ AR FA ZH JA KO (Türkçe kaynak).
Çalışma anında `design/*.dc.html` içindeki `tdI18n` bölümü ekrandaki metinleri çevirir; özel adlar (kulüp, kişi, şehir) çevrilmez.
